# Oxygène Studio

A 1970s space-synth studio that runs in the browser: ensemble strings with phaser, a mono lead, a bass,
an analogue-style drum box, wind and effects, a sound programmer, and a multitrack timeline to build whole pieces.

**Open it:** https://instantbook.github.io/oxygene-studio/

On a phone, open the link in Safari (iPhone) or Chrome (Android) and choose **Add to Home Screen**.
After the first visit it also works offline.

- Everything is one page of plain JavaScript and Web Audio; no samples, no libraries, nothing is sent anywhere.
- Songs and your own sounds are stored in the browser on your device. Use the FILE tab to save a song as a file.
- iPhone: the ring/silent switch mutes web audio.

A fan project inspired by the sound of Jean-Michel Jarre's *Oxygène*; not affiliated with the artist.
